# Changelog

## 1.0.0

First public release of Neo Nursery.

### Nursery
- Zelda Day Care onboarding and the BABY MONITOR Key Item.
- Three persistent Nursery resident slots.
- 24-hour real-time Nursery Egg claim cooldown and approximately 10-minute Egg incubation.
- Offscreen hatch reconstruction, per-resident real-time care clocks, and PAUSE CARE.

### Care
- Corrected BERRY JUICE feeding art so it progresses intact -> half-eaten -> mostly-eaten -> gone.
- FOOD, FUN, CLEAN, sleep, digestion, waste, illness, medicine, age, weight, Friendship, preferences, and COND.
- Three PLAY minigames: BOUNCE, MATCH, and MEMORY.
- Thought-bubble reactions and slower discoverable flavor conditions.
- Species-specific schedules, movement profiles, and official Crystal animation flourishes.

### Progression
- 0-100 Nursery Friendship synchronized to Crystal's hidden happiness.
- Adoption to party/PC at 100 Friendship.
- First-milestone Everstone reward.
- Return dropoff for previously raised Baby Pokémon.
- Persistent Friendship, weight, shiny state, Sprite Style, and Pokémon identity.
- Happiness evolution support for reconstructed babies.

### Pokémon
- Crystal's eight official Baby Pokémon.
- Eleven Nursery-exclusive reconstructed babies: Mikon, Monja, Gyopin, Para, Hinazu, Konya, Puchikon, Betobebi, Pudi, Baririna, and Tsuinzu.
- First-time species Friendship milestones unlock random undiscovered Neo Baby Eggs without duplicates.
- Nursery-generated Eggs use 1-in-20 shiny odds.
- CRYSTAL / NEO Sprite Style for official babies.

### Compatibility
- PokeSurvive RAND TYPES, RAND STATS, RAND MOVES, palettes, camping clock, save/reload, adoption, evolution, and species-pool isolation compatibility.
- Mutant Monster Lab per-Pokémon palette persistence.
- Official Crystal sprites are reconstructed from the player's imported game data at runtime instead of shipping extracted official sprite PNGs.

### Release cleanup
- Removed all START-menu development and QA tools.
- Removed stale bytecode, backup source, and development pack metadata.
- Added GitHub release metadata for `GawdMode/Neo-Nursery`.
